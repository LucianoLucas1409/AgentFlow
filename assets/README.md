# Guia para as imagens do case

Esta pasta deve conter apenas imagens preparadas especificamente para publicação.

## Arquivos sugeridos

```text
assets/
├── home.png
├── agente-qualitor.png
├── investigacao.png
├── agentdesk.png
├── tendencias.png
└── monitoramento.png
```

## Padrão visual

- Preferir PNG ou WebP.
- Usar largura consistente, entre 1400 e 1800 pixels.
- Recortar áreas que não fazem parte da demonstração.
- Usar os mesmos dados fictícios em todas as telas para manter coerência narrativa.
- Adicionar uma legenda no README explicando o que a imagem demonstra.
- Evitar imagens enormes; comprimir sem prejudicar a leitura.

## Dados fictícios sugeridos

- Empresa: `Empresa Demonstração`.
- Unidade: `Filial Demo 001`.
- Usuário: `usuario.teste`.
- Equipamento: `ESTACAO-DEMO-01`.
- Chamado: `DEMO-0001`.
- Sistema: `Sistema Exemplo`.
- Domínio: não mostrar, mesmo que seja fictício, se não for necessário.

Antes de adicionar qualquer imagem, conclua a seção de screenshots do `PUBLICATION-CHECKLIST.md`.
